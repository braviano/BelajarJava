## ▶️ Menjalankan Program

Pastikan **JDK (Java Development Kit)** sudah terinstal.

Compile file Java:

```bash
javac NamaFile.java
```

Jalankan program:

```bash
java NamaFile
```

Contoh:

```bash
javac Main.java
java Main
```
